# Desafio2_M-dulo5_DIO_PowerBI
Este repositório abriga um Relatório de Vendas e Lucros com Data Analytics com Power BI.

O projeto utiliza a base **Financial Sample** e explora recursos de navegação, indicadores e visualizações interativas para facilitar a interpretação das informações financeiras.

## Objetivos do desafio

O projeto busca melhorar a experiência do usuário na exploração dos dados, considerando os seguintes aspectos:

- **Posicionamento:** organização dos elementos para facilitar a leitura.
- **Contraste:** diferenciação dos elementos visuais para melhorar a compreensão.
- **Proporção áurea:** consideração das proporções e da distribuição dos componentes do relatório.
- **Segmentação dos dados:** utilização de filtros para explorar diferentes informações.
- **Navegação entre páginas:** implementação de botões e menus para facilitar a movimentação pelo relatório.
- **Interatividade dos visuais:** utilização de indicadores para alternar entre diferentes perspectivas de visualização dos dados.

## Estrutura do relatório

### 1. Sales Report

Página dedicada à análise geral das vendas e dos indicadores financeiros.

Principais recursos:

- Indicadores de vendas totais (*Sales*) e unidades vendidas (*Units Sold*).
- Indicadores de descontos (*Discounts*) e custo dos produtos vendidos (*COGS*).
- Gráfico de vendas por período.
- Visualização de vendas por segmento.
- Matriz de vendas por mês e canal de distribuição.
- Filtro de datas para delimitar o período analisado.
- Navegação entre as páginas por meio de botões e menus.
- Indicadores de navegação para alternar entre diferentes perspectivas dos visuais.

### 2. Detalhes de Vendas

Página voltada à análise detalhada das vendas, permitindo explorar os dados por país e produto.

Principais recursos:

- Vendas por país (*Sales X Country*).
- Relação entre vendas e unidades vendidas (*Sales X Units Sold*).
- Distribuição de unidades vendidas por faixas de valores (*Buckets*).
- Unidades vendidas por produto.
- Indicadores de navegação para alternar entre diferentes perspectivas dos visuais.
- Botões para facilitar a navegação entre as páginas do relatório.

## Interatividade e navegação

Um dos principais aspectos do projeto é a utilização de recursos interativos para tornar a análise mais dinâmica.

### Navegação entre páginas

Foram utilizados botões e menus de navegação para permitir que o usuário se movimente entre as páginas do relatório de maneira mais intuitiva.

### Indicadores e alternância de visuais

Os indicadores permitem alternar entre diferentes perspectivas de visualização, possibilitando explorar os dados de formas distintas sem depender exclusivamente de uma única apresentação visual.

Esse recurso contribui para uma experiência mais flexível, permitindo que o usuário escolha a visualização mais adequada à análise que deseja realizar.

### Filtros e segmentação

Os filtros permitem delimitar os dados apresentados, facilitando a análise por período e a exploração das informações disponíveis nos visuais.

## Tecnologias e recursos utilizados

- **Power BI Desktop:** desenvolvimento e organização do relatório.
- **Financial Sample:** base de dados utilizada nas análises.
- **Indicadores:** alternância entre diferentes perspectivas dos visuais.
- **Botões e menus de navegação:** movimentação entre as páginas.
- **Filtros e segmentações:** exploração interativa dos dados.
- **Gráficos, cartões e matrizes:** apresentação dos indicadores e comparação dos resultados.

## Resultado

O projeto resultou em um relatório financeiro interativo, organizado em duas páginas, que permite analisar as vendas sob diferentes perspectivas.

A combinação de indicadores, filtros, visuais e recursos de navegação facilita a exploração dos dados e melhora a experiência do usuário na interpretação das informações financeiras.
